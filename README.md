# Central Ar — App de Gestão

App de gestão para empresa de refrigeração/climatização, em um único arquivo HTML (`app-central-ar.html`), sem backend próprio.

Cobre: financeiro (fluxo de caixa), vendas, agenda, orçamentos, relatórios (serviço realizado, fotográfico, checklist de manutenção) e cadastros (clientes, serviços, produtos, materiais, funcionários).

## Uso

Abra `app-central-ar.html` diretamente no navegador, ou publique via GitHub Pages.

Por padrão os dados ficam salvos no `localStorage` do navegador. Para sincronizar entre aparelhos, configure a conexão com o Google Drive em **Configurações → Sincronização** dentro do app.
